# 🗒️ Django Notes App (with Search)

A simple Notes application built with Django that allows users to create, manage, and search notes.

---

## 🚀 Features

* Create notes
* View all notes
* Update notes
* Delete notes
* Search notes by title or content

---

## 🛠️ Tech Stack

* Python
* Django
* SQLite

---


## ⚙️ Setup

```bash id="9rgdnn"
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

python -m venv venv
venv\Scripts\activate   # or source venv/bin/activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

---

## 🔍 Search Functionality

Users can search notes using keywords.
The app filters results based on matching titles or content.
